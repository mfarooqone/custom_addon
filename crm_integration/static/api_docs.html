CRM Integration API

REST endpoints to create and update contacts with contact type support.

Base URL:

Authentication

Every request must include the company CRM API key from Settings → CRM Integration. CRM integration must be enabled for the company.

Header (recommended)

X-CRM-API-Key: <your-api-key>

Bearer token

Authorization: Bearer <your-api-key>

Create Contact

POST /api/crm/v1/contacts

Required: name, contact_type

contact_type values: customer, vendor, employee

Request body

{
  "name": "John Doe",
  "contact_type": "customer",
  "email": "john@example.com",
  "phone": "+971500000001",
  "mobile": "+971500000002",
  "street": "Business Bay",
  "street2": "Tower A",
  "city": "Dubai",
  "zip": "00000",
  "country_code": "AE",
  "state_name": "Dubai",
  "vat": "123456789",
  "website": "https://example.com",
  "ref": "CRM-001",
  "company_name": "Example LLC",
  "is_company": false,
  "active": true
}

Update Contact

            

                PUT
                /api/crm/v1/contacts/<partner_id>
            

            
Send only the fields you want to change. Request body is required.

            
Request body

            
{
  "email": "john.updated@example.com",
  "phone": "+971500000099",
  "contact_type": "vendor",
  "city": "Abu Dhabi",
  "country_code": "AE"
}

            
Example

            

            
Success response 200

            
{
  "success": true,
  "data": {
    "id": 42,
    "name": "John Doe",
    "contact_type": "vendor",
    "contact_code": "VEND00012",
    "vendor_id": "VEND00012",
    "email": "john.updated@example.com"
  }
}
